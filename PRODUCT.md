# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Stack

React frontends and a Flask backend, confirmed for local development on Parrot.
The two apps have separate interfaces and call separate API routes. Hosting
target remains open pending an API and native QR decoding check on the host.

## Users

Rushyaant uses the lab to learn full-stack security tooling and demonstrate
two distinct portfolio projects. Work advances in small steps he can run,
inspect, and explain.

## Product Purpose

The red app produces controlled synthetic email and QR examples. The blue
app accepts saved examples, extracts evidence, and reports indicators for
human review. Success is a reproducible red-to-blue file handoff.

## Capabilities and Constraints

Use fictional `.test` destinations and marked simulation messages. Blue triage
inspects saved bytes locally and never navigates to extracted URLs. Uploaded
data is processed in a temporary directory. The first milestone exposes API
endpoints and a terminal walkthrough. Visual design is a later decision.

## Evidence on Hand

The original prototype defines ten cases, eight with intended indicators and
two controls. It includes three QR images and independently checks results.
